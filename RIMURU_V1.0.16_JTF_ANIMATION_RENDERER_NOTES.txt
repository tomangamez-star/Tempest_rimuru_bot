RIMURU v1.0.16 — JTF ANIMATION RENDERER

INSTALL
Copy the files in this archive into the bot root and allow matching files to be replaced.
The new motion-stars folder belongs at src/assets/motion-stars, beside src/assets/motion-borders and src/assets/ranks.
No environment variables are required.
