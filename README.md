# JTF Starter Skins

Ten original characters, one default skin each. All images are 1024 x 1536 PNGs with genuine alpha transparency. Preserve the PNG files; converting to JPEG removes transparency.

## GitHub placement

Copy the included assets/skins folder into your repository root. Example: assets/skins/kael/default.png. Keep the lowercase folder and file names. roster.json records stable character and skin IDs for later integration; it does not activate any bot feature by itself.

## Future skins

Keep the character ID and add new skin files inside that character folder. Use these default images as visual references to preserve face, hair and identity. Titles here describe characters; they are separate from player achievement badges.

## Artwork provenance

Created using the built-in image generation tool. Full generation prompts are included in ART_PROMPTS.json. No bot code, prices or unlock rules are included.
